One sentence that brings back a childhood memory: the last summer before
a move, a tin of marbles buried under the mango tree with the best
cat's-eye on top, and a grown-up still wondering whether the boy who
lives there now ever found them. The program writes exactly that text
to `/output/entry.txt` on every run, byte for byte.

## Run it

```sh
node main.ts
```
